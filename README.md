# School Management System 2.0

A secure, scalable, multi-tenant School ERP platform.

## Architecture

- Frontend: Flutter
- Backend: NestJS
- Database: PostgreSQL
- ORM: Prisma
- Authentication: Custom Authentication
- Cache: Redis
- Background Jobs: BullMQ
- Event Streaming: Apache Kafka
- Infrastructure: Docker

## Project Structure

- apps/backend: NestJS backend
- apps/flutter_app: Flutter application
- packages: Shared API and event contracts
- infrastructure: Infrastructure configuration
- docs: Architecture and security documentation

## Core Principles

1. Security first.
2. Strict multi-school data isolation.
3. Least-privilege access control.
4. Reliable database transactions.
5. Scalable architecture.
6. Comprehensive automated testing.
